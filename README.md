# 🎨 Art Gallery Management System  

A **web-based platform** designed to **automate and streamline** art gallery operations, allowing seamless **management of artists, artworks, and inquiries**.  

## 🚀 Features  
- 🎭 **Artist Management** – Store and manage artist information.  
- 🖼️ **Art Categories & Mediums** – Organize artwork by type and medium.  
- 📩 **Inquiry Handling** – Allow users to inquire about artwork.  
- 📊 **Dashboard** – Overview of gallery activities.  
- 🔐 **Admin Panel** – Manage users and gallery operations.  

## 🛠️ Technologies Used  
- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** PHP  
- **Database:** MySQL  
- **Server:** Apache
